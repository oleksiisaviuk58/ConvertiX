## ConvertiX
ConvertiX is a currency conversion web application built with ASP.NET Core.

The project allows users to convert between different currencies using up-to-date exchange rates retrieved from an external API. 
The main goal of the project is to gain hands-on experience in building web applications with ASP.NET Core, integrating third-party 
services, implementing Dependency Injection, and applying Clean Architecture principles.

# Features
- Currency conversion.
- Retrieval of current exchange rates from an external API.
- Input data validation.
- Error handling for invalid requests and external service failures.
- Displaying conversion results through a web interface.
